### 桌面端：宽度大于 760px

- 两栏同一网格，列宽约 `1 : 1.7`，左栏最小约 290px，栏间距 16px。父级使用 `minmax(0, …)` / `min-width: 0` 避免撑出页面。
- 左右栏各一个完整容器：顶部、底部齐平；内边距统一 20px；右侧图表与转化分析用分隔线组织，不再套多层卡片。
- 两栏标题区高度至少 42px，标题字号、字重、顶部位置一致；返回按钮在右侧标题区内垂直居中。
- 左侧搜索与排序控件统一高度，间隔 12px；右侧三个资源指标等宽，标签在上、数字在下，数字基线一致。
- 资源列表普通行统一约 68px（含边框）。标题与类型/年份左对齐，打开次数与占比右对齐；序号定宽，数字用等宽数字样式。
- 选中行使用浅背景与左侧强调线；不要在副标题中追加会换行的「正在分析」等文字，避免行高跳动。
- 顶部四项整体指标等宽，标签、数字、说明分别对齐。外层留白参考上下 24px、左右 26px；主要区块间距 16–18px。
- 趋势图参考高度 220px，随容器宽度重新布局；小屏减少坐标标签，不能把整张图等比缩小到文字不可读。

### 手机端：宽度不大于 760px

- 整体指标改为两列；列表占满可用宽度。
- 点击资源后，**趋势与转化分析直接展开在该资源行下方**。切换资源时收起旧分析，展开新分析；不能统一放在长列表末尾或页面顶部。
- 保证切换后选中资源仍在可视范围内；不出现空白占位，不丢失筛选与排序状态。
- 展开内容统一内边距约 14px；较窄屏幕下转化分析纵向排布。页面不横向滚动，触摸控件提供约 44px 点击区域。

## 必要交互与口径

- 时间、类型影响整体指标、资源列表及分析区域；顶部整体指标始终代表当前类型整体，点击资源不改变其范围。
- 未选资源时右栏显示整体趋势；选中后，右栏标题、三个指标、趋势和转化数据同时切换。提供「返回整体」，保留时间、类型、搜索、排序。
- 支持搜索、清空搜索、打开次数/转化率/复制成功排序及升降序。搜索只过滤列表；若当前资源被搜索隐藏，则返回整体分析。
- 趋势支持鼠标/触摸查看时间点、前后按钮查看；读数显示日期、打开次数、去重访客。键盘可完成主要操作。
- 加载、无数据、搜索无结果、接口错误均需有明确状态；不能把失败显示为零，切换时避免容器高度突然塌陷。
- 去重访客是匿名浏览器数，整段去重不可由每日相加；转化率按同一资源、同一会话计算；今天标明截止时间，按 `Asia/Shanghai` 展示。复制与打开分别计数。

## 验收与实现边界

- 在 320、390、768、1024、1440px 检查：无横向溢出，控件不重叠，标题与数值不被截断；桌面两栏顶边、底边、标题起点一致。
- 连续切换资源、搜索、排序、返回整体，列表与图表始终对应；手机端展开位置正确，选中状态不引起列表行高变化。
- 数据为空或只有一个时间点时，图表和布局仍成立；标题较长时允许可读换行，必要时整行增高，禁止截掉标题。
- 保持系统字体；用 Vue 状态驱动视图，资源关联遵守 ShareID 业务主键及 PublicLink / Link 边界；数据查询在 Store 层。
- 不新增依赖，不修改现有后台导航架构。真实采集、存储、API 按项目规范实现，本说明不规定其接口细节。
- 修改 `web/` 后执行 `make web && go build ./...`；提交前执行项目要求的 lint，单个 PR 控制在 300 行以内。
